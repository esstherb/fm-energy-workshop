# FM Energy Workshop

> **Workshop Prototype** — This project is a learning exercise and not intended for production use.

## Goal

Predict the next hour's electricity consumption for a building and display the forecast on an interactive dashboard.

## Planned Tools

- **Python** — data processing, feature engineering, and model training
- **Streamlit** — interactive dashboard for visualising predictions
- **Neon Postgres** — cloud database for storing consumption data and forecast results
